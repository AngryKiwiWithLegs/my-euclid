# 统一作答与本地迁移模型

## 统一答卷

一次训练会话对应一条 `practice_sessions` 记录。每次键盘输入、手写板书或纸质答案附件都作为同一会话下独立的 `responses` 版本保存；不会因为切换作答方式而覆盖已有内容。`response_attachments` 只保存归档文件的安全标识、原始名称、哈希和 MIME 类型，实际附件与题源原件一样存储在应用私有档案目录中。

| 实体 | 用途 | 关键字段 |
| --- | --- | --- |
| `practice_sessions` | 训练会话与题目引用 | `reference_key`、开始/结束时间、状态。 |
| `responses` | 同一会话的文本、手写或纸质作答版本 | `answer_format`、内容、草稿/提交状态、版本号。 |
| `response_attachments` | 答案照片、扫描件或板书导出附件 | 原始名称、归档名称、哈希、文件大小。 |
| `backup_audits` | 导出、预检、恢复等迁移操作的审计线索 | 操作类型、备份 ID、状态、时间与摘要。 |

## 备份包

导出文件为 `*.myeuclid-backup.zip`，内容是一个完整本地快照：`manifest.json`、SQLite 数据库、题源原件和答卷附件。导出前数据库会执行检查点；清单记录包格式版本、创建时间和每个文件的 SHA-256。恢复前系统读取清单、验证文件路径和哈希，并向用户显示包的时间、资料数量、答卷数量和附件数量。

恢复采用**覆盖替换**策略。为避免正在使用的 SQLite 文件被直接覆盖，主进程先将当前数据库和档案目录保存为自动恢复点，然后关闭数据库连接、替换为已验证的快照、重新初始化数据库并重载工作台。该操作只会在用户经过预检并明确确认后执行。

> 恢复会覆盖当前本地档案、作答和训练记录。界面必须先完成预检并展示当前与备份的数量摘要；用户可先导出当前备份再继续。

## IPC 边界

渲染进程不能传入任意文件路径。所有答卷附件、备份导出和恢复包都必须经由主进程的原生文件选择框。预加载层只暴露会话保存、附件选择、备份导出、备份预检和确认恢复这五类白名单操作；任何失败都返回结构化错误，不静默跳过文件或合并数据。
