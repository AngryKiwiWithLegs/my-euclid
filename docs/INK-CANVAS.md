# 笔迹作答与回放

笔迹作答不会覆盖同一训练会话中的键盘文本或纸质附件。每次保存会创建一条 `handwritten` 答卷版本，并写入其图层、笔画与预览快照；笔画记录使用归一化坐标、压力和相对时间，因而能够按原始顺序回放，也不会依赖某一台 Mac 的屏幕尺寸。

| 实体 | 作用 | 保存内容 |
| --- | --- | --- |
| `ink_layers` | 一份笔迹答卷中的可见图层 | 名称、排序、可见状态与默认笔色。 |
| `ink_strokes` | 图层内不可变的书写轨迹 | 画笔/橡皮擦类型、笔宽、归一化点序列、压力、相对时间和边界框。 |
| `ink_snapshots` | 当前版本的快速预览与回放画布信息 | SVG 预览、画布逻辑尺寸与创建时间。 |

画布只接收 Pointer Events，并使用压力值（如果设备提供）调节笔画宽度。撤销和重做首先在渲染进程内完成；“保存笔迹版本”才会经由受限 IPC 写入 SQLite。保存后，主进程不会暴露任意文件路径或数据库语句。

备份包无需额外处理笔迹目录：笔画、图层和 SVG 快照都存储在 SQLite 中，因此会自动进入现有的哈希清单、恢复预检和恢复点流程。笔迹画布暂不进行 AI 图像判卷；后续评分模块可读取 SVG 快照和结构化笔画序列，按用户主动触发的规则送入分析流程。
