# 产品规格书：My Euclid

## 1. 定位

My Euclid 是面向单个学生的 Apple Silicon macOS 备考客户端。产品目标不是把 PDF 堆叠成题库，而是把用户自主导入的竞赛资料、线上解答和纸质手写答卷统一转化为可审阅的训练证据，从而支持冲击欧几里得竞赛满分的长期训练。

## 2. 核心体验

### 2.1 本地档案化题库

用户可以拖入单个 PDF、扫描件、图片或文本，选择整个文件夹，或粘贴资源链接导入。每份原始资料保持本地原样保存。AI 在用户开启智能处理后识别文字，建议试卷、大题、小问的层级边界，并生成知识点、主次考点、难度、题型、解法、来源、得分点与状态等标签。所有建议先进入审核队列，用户可逐项编辑、批量确认或撤回。

### 2.2 统一作答与判卷

一份试卷既可在软件内键盘输入 LaTeX，也可用触控板或数位板手写，或上传纸质答案照片。纸质整卷上传时，系统先识别页面、题号、作答区域和手写内容，再按小问拆分到同一套 `Attempt` 记录。线上与纸质作答的后续流程完全一致：评分、得分点证据、错因、AI 讲解、错题本、统计与 IRT 更新都共享同一数据模型。

### 2.3 报告、讲解与深度训练

每次提交生成一份可溯源报告：总分、每小问预估分、评分依据、题目考察点、丢分步骤、错因与模块细化分析。长期页面汇总答题量、正确率、时间、能力雷达和进步曲线。错误题旁提供“AI 讲解”入口，导师按启发式顺序讲解必备知识、切入点、思维来源、同类旧题和变体追问，并给出至少三种独立思路。深度专项训练在知识依赖图上寻找薄弱节点，基于 IRT 动态选择上游补弱题、当前层巩固题和更高难度迁移题。

## 3. 关键功能与验收标准

| 功能 | 首次可用版本验收标准 |
| --- | --- |
| 资料导入 | 可新增资料、保留原件、记录来源并展示导入状态。 |
| OCR 与切分 | 生成可人工修订的小问草案，且每一小问能回到原页。 |
| 题面 | 用干净 LaTex/Markdown 排版展示，原图可随时对照。 |
| 多形态作答 | 单题可保存键入、手写、照片三类附件，彼此不覆盖。 |
| 纸质整卷判卷 | 上传试卷后可将页面与题号对应，进入相同评分与报告流程。 |
| AI 反馈 | 展示预估分、评分证据、步骤缺口和错因；用户可标记“采纳/不采纳”。 |
| 套卷模考 | 支持 10 题、150 分钟计时、交卷前隐藏答案、交卷后统一报告。 |
| 数据迁移 | 可导出完整可读清单与可恢复归档；导入时先预览冲突。 |

## 4. 非目标与边界

产品首发不包含社交、公开排名、多用户协作或在线商业题库。排位预测仅在用户导入足够可靠的官方统计口径后作为参考指标显示，不把推测值表述为官方排名。AI 分数是预估，报告必须可展示所依据的题目、参考解法与用户作答证据。
