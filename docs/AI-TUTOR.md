# AI 互动讲解：逐次授权与本地审计

My Euclid 的互动讲解只由用户在**已发布题目**的“讲解”入口主动触发。每次调用前，桌面端会先展示提供商、模型、题面文本和发送边界；用户确认后才生成一次性、十分钟有效的授权令牌。令牌被使用后立即失效。

## 发送与保留边界

> 互动讲解请求只发送已发布题目的**题面文本**和所选模型标识。

原始资料、页面扫描图、纸质答卷附件、笔迹二进制、训练答卷文本、API 密钥和本地备份内容均不随互动讲解请求发送。API 密钥只在 macOS Keychain 可用时于主进程短暂解密使用；不会返回到 renderer、写入 SQLite、日志、Git 仓库或备份包。

| 环节 | 系统行为 | 是否写入报告 |
| --- | --- | --- |
| 用户查看发送范围 | 创建一次性授权预览，不发起网络请求 | 否 |
| 用户确认生成 | 发送题面文本，校验 JSON 后保存本地会话 | 否 |
| 用户追问 | 保存用户问题与提示型 AI 回复到同一会话 | 否 |
| 无效模型响应 | 拒绝保存会话，保留错误边界 | 否 |

## 讲解计划质量门槛

模型返回的结构化计划必须具有至少三种**实质不同且完整**的方法，每种方法都需包含名称和推导轮廓。计划还必须包含必备知识、切入点、思维来源、同类题型、至少两个变式和一个苏格拉底追问；缺少三方法、切入点或追问时，系统拒绝响应且不创建本地会话。

追问阶段要求模型优先给出简洁提示，除非学习者在已尝试后明确要求完整解答。会话及其消息仅保留在本地 SQLite，便于回看自己的提问路径，但不会影响确认评分、报告聚合或 IRT 能力估计。

## 当前验证范围

`scripts/verify-tutor-flow.mjs` 使用本地模拟的 OpenAI 兼容服务，验证未授权运行被拒绝、发送预览不泄露密钥、三方法计划会落盘、追问保存双向消息，以及两方法的无效 JSON 不创建会话。该测试不等同于真实提供商或 macOS Keychain 验证；两者须在目标 Apple Silicon Mac 上完成。
