# 导入导出规范

## 导入

| 导入方式 | 输入 | 预期结果 |
| --- | --- | --- |
| 文件拖拽 | PDF、图片、Markdown、纯文本 | 创建原件档案并进入 OCR/切分审核队列。 |
| 文件夹导入 | 题目、参考解答、答案照片混合目录 | 建立来源树并提示用户确认文件角色。 |
| URL 导入 | 可访问的资料页面或 PDF 链接 | 下载快照并记录 URL、访问时间和本地校验值。 |
| 纸质答卷上传 | PDF、JPG、PNG、HEIC | 页面矫正、题号识别、手写 OCR、作答区域草案。 |
| 迁移包导入 | `.myeuclid` 归档 | 显示摘要、冲突、附件大小与覆盖策略后恢复。 |

## 导出

系统提供两种导出方式。第一种是**可读报告**，以 Markdown、PDF 或 CSV 导出指定题目、训练会话、错题清单和趋势数据。第二种是**可恢复归档**，以 `.myeuclid`（ZIP 容器）导出 `manifest.json`、SQLite 数据快照、附件索引、原件引用与报告。大型原件可选择“包含”“仅保留外部引用”或“排除”。

迁移包绝不包含 API 密钥。导入时基于 `id`、校验值和修改时间进行预览，用户可选择跳过、合并、复制或覆盖。
