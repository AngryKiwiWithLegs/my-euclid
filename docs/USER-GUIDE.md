# My Euclid 用户手册

> 写给正在使用或准备使用 My Euclid 备考欧几里得数学竞赛（Euclid Mathematics Contest）的同学。不需要任何编程知识，读完这一篇就能上手全部功能。

---

## 1. My Euclid 是什么

My Euclid 是一款运行在 **Mac（Apple Silicon 芯片）** 上的个人备考软件。它做的事情可以概括为一句话：

**把你手里的竞赛资料（试卷 PDF、扫描件、照片）变成一个可以反复训练、打分、复盘的私人题库，并且所有数据都保存在你自己的电脑上。**

它的几个核心特点：

- **本地保存**：题库、作答、评分、报告全部存在你电脑里，不需要注册账号，没有服务器。
- **AI 可选、按需启用**：只有你主动使用 AI 功能（自动审核、判卷、讲解、出题）时，相关文字内容才会发送给你自己配置的 AI 服务。不配置 AI，软件照样能完成导入、OCR、手写作答、模考和人工评分。
- **可追溯**：每一道题都能回链到原始资料的具体页码；每一条 AI 评分都会先存成"草案"，经你确认后才进入正式报告。

## 2. 安装与启动

### 2.1 安装（推荐方式）

1. 拿到 `My Euclid-arm64.dmg` 安装镜像文件，双击打开。
2. 把 **My Euclid** 图标拖入 **Applications（应用程序）** 文件夹。
3. 首次打开时，macOS 可能提示"无法验证开发者"。这是因为本软件暂未经过 Apple 公证，属正常现象：
   - 方法一：在"应用程序"文件夹里**按住 Control 键点击** My Euclid，选择"打开"，再点"打开"；
   - 方法二：到 **系统设置 → 隐私与安全性**，找到相关提示，点"仍要打开"。
4. 之后就可以像普通 App 一样从启动台打开。

> 系统要求：Apple Silicon（M1 及之后）的 Mac，macOS 12 或更新版本。

### 2.2 数据存放位置

所有数据都在这个文件夹里（可以在访达中按 `Cmd+Shift+G` 前往）：

```
~/Library/Application Support/My Euclid/
├── my-euclid.sqlite    ← 题库、作答、评分、报告的数据库
├── archive/            ← 你导入的原始文件（永久保留原件）
├── secure/             ← AI 服务密钥（系统加密存储）
└── ai-review.log       ← AI 自动审核的运行日志
```

想彻底清空所有数据：退出软件后删除整个"My Euclid"文件夹即可。

## 3. 认识工作台

打开软件后，左侧有 7 个导航区：

| 页面 | 用途 |
| --- | --- |
| **工作台** | 首页概览，导入资料的三个入口 |
| **题库档案** | 查看已发布的正式题库，搜索、筛选、发起讲解/变式/训练 |
| **审核工作台** | 修订 OCR 文本、框选局部识别、切分题目、发布到题库 |
| **训练会话** | 单题训练、全真模考、IRT 专项训练 |
| **错题证据** | 人工评分、AI 判卷、查看每道题的得分依据与错因 |
| **报告与轨迹** | 得分率、模块分析、错因分布等长期统计 |
| **AI 服务** | 配置 AI 服务商和密钥 |

## 4. 五分钟上手：从一份试卷 PDF 到一套模考

1. **导入资料**：在"工作台"点击 **导入资料** → **从本机选择资料**，选择一个或多个 PDF / 图片 / 文本文件（单文件不超过 100 MB）。
2. **等待处理**：软件会把原件复制进本地档案，并自动提取文字（PDF 直接提取文字层；图片和扫描件用本地 OCR 识别，无需联网）。
3. **AI 自动审核（可选）**：如果你已配置 AI 服务，导入后会自动开始"校对 OCR → 切分题目 → 补全标签 → 发布到题库"，全程无需操作；没有配置 AI 也没关系，你可以在"审核工作台"手工完成同样的事（见 §5.3）。
4. **去题库看看**：打开"题库档案"，你会看到已发布的题目，每道题都标注了来源文件和页码。
5. **组建模考**：进入"训练会话" → "全真 150 分钟模考"，勾选 10 道题（或点击"AI 智能组卷"自动挑选），开始计时作答。

## 5. 功能详解

### 5.1 导入资料

支持格式：**PDF、PNG、JPG/JPEG、HEIC、TXT、MD**，单文件不超过 100 MB，一次可选多个文件。

- PDF：自动按页拆分；有文字层的直接提取，扫描版会渲染成页面图片供查看和框选识别。
- 图片：本地 OCR 识别文字。
- 文本：直接作为一页文本。
- 导入"纸质答卷"与导入资料的区别只在归类标签，后续流程一致。

导入记录会出现在"题库档案"下方的"已归档的真实资料"列表里。

### 5.2 OCR 与人工修订（审核工作台）

左侧选择资料，中间是页面预览，下方是可编辑的 OCR 文本：

- **修订文本**：直接在文本框里改正识别错误，点 **保存本页 OCR**，本页即标记为"已审核"。
- **局部框选识别**：在页面图片上拖拽框选任意区域（比如一道题或一个公式），软件会对这个区域单独做一次更精细的 OCR，识别结果作为独立证据保存；点"采用文本"会追加到编辑区。
- **页面切换**：顶部的 P.1、P.2 标签可切换页面，每页独立保存审核状态。

### 5.3 题目切分与发布

右侧"题目与小问切分"面板：

1. 点 **新增题目**，为每道大题填写题号、标题和题面文本（可以多选来源页）。
2. 点 **确认并写入题目档案** 保存草案。
3. 点开 **手动发布选项**，为每道题补全：来源名称、主考点、题型（必填），以及年份、难度（1–5）、预计用时、满分、评分要点等（选填）。
4. 发布后，题目就进入正式题库。

> 如果你开启了 AI 自动审核，以上切分和发布由 AI 自动完成，人工发布面板主要用于抽查和纠错。

### 5.4 题库档案

- 顶部搜索框可按题号、来源、知识点、方法搜索；下拉框按主考点筛选。
- 每道题显示：来源 · 年份 · 题号、原件文件与页码、小问数量、标签、难度。
- 三个操作按钮：
  - **AI 变式**：让 AI 仿照这道题的题型和难度生成一道新题，自动发布到题库（需配置 AI）。
  - **讲解**：打开 AI 互动讲解面板（见 §5.7）。
  - **训练**：进入训练页（注意：目前单题训练页显示的是内置示例题面，见 §9 已知限制）。

### 5.5 三种作答方式（训练会话）

- **键盘作答**：直接打字，支持写下完整推理过程。离开输入框会自动保存草稿；每次保存都是独立版本，不会互相覆盖。
- **手写板书**：用触控板或数位板手写，支持多图层、笔/橡皮工具，保存为带时间戳的笔迹档案。
- **上传纸质答案**：选择照片或扫描件，文件复制进本地档案并绑定到本次作答。

### 5.6 全真模考

- 从题库勾选**恰好 10 道**题，或使用 **AI 智能组卷**（AI 会按真实 Euclid 卷的结构自动平衡模块与难度；AI 不可用时自动回退为本地均衡挑选）。
- 标准时长 **150 分钟**；点"开始"后进入倒计时。
- 作答界面逐题切换，左栏显示每题的作答状态（未答/草稿/已提交）。
- 点 **交卷** 后试卷锁定为"已提交"，之后在"错题证据"和"报告与轨迹"里评分复盘。
- 注意：计时按"开始时刻的真实时间"计算，**中途退出软件不会暂停计时**，请一次完成。

### 5.7 AI 功能（需先配置 AI 服务）

#### 先配置：AI 服务页

1. 点 **添加服务配置**，填写：
   - 服务名称：随意，如"我的 AI 服务"；
   - HTTPS API 基地址：形如 `https://api.example.com/v1`（必须是 OpenAI 兼容接口，必须 HTTPS）；
   - 模型标识：服务商提供的模型名；
   - API 密钥：只在输入时可见，保存后加密存放，界面和备份包里都不会再显示。
2. 可添加多个服务并切换默认项；"测试连接"会检查连通性并列出可用模型。
3. 密钥保存在 macOS 系统级加密存储中，不写入数据库、不进入备份包。

#### AI 自动审核

导入资料后自动运行：逐页校对 OCR 错误 → 把整份资料切分成题目和小问 → 补全来源、考点、难度等标签 → 自动发布到题库。单页或单题失败不影响其余；完全失败的页面会按整页文本兜底归档，之后可手工修订。开关在"审核工作台"右上角（**导入后自动审核：开/关**）。

#### AI 判卷（错题证据页）

这是隐私控制最严格的功能，分三步：

1. 选择训练会话和答卷版本，**手动粘贴本题题面**，设定满分；
2. 点"查看本次发送范围"，软件会**完整展示将要发送的题面和答卷文本**、所用服务和模型；
3. 你确认后才会真正发送。AI 返回的评分（总分、逐条得分点与依据、错因分类、模块拆分）只会保存为**待审核草案**，你核对无误后手动确认，才会进入正式报告。

#### AI 互动讲解（题库档案 → 讲解）

AI 会为题目生成结构化的讲解计划：必备知识 → 切入点 → 思路来源 → **至少三种独立解法**（各含关键技巧与常见误区）→ 同类题型 → 变式追问，最后以一个苏格拉底式问题引导你继续思考。你可以在面板里继续追问，AI 会给提示而不是直接给答案。

#### 发给 AI 的内容一览

| 功能 | 会发送 | 不会发送 |
| --- | --- | --- |
| 自动审核 | 资料的 OCR 文本 | 原始图片、PDF 文件 |
| AI 判卷 | 你确认的题面文本 + 该版本答卷文本 | 纸质附件、扫描图片、笔迹数据 |
| 互动讲解 | 已发布题目的题面文本 | 原件、附件、你的其他作答 |
| 变式 / 组卷 | 题面文本 / 题库清单（题号、考点、难度） | 附件与个人作答 |

每次 AI 判卷都会在本地数据库留下审计记录（时间、服务、发送内容的字数摘要、结果状态），可在数据文件中查证。

### 5.8 人工评分与错题证据

- **建立评分档案**：选择会话和答卷版本，录入总分、结论摘要、逐条评分依据（得分点 + 得分 + 依据 + 作答摘录）、错因（概念/方法/推理/完整性/计算/表达/用时等 8 类 × 轻/中/重 3 档）和模块拆分。确认前软件会校验"各依据得分合计 = 总分"。
- **AI 草案对比**：AI 判卷生成的草案会与你的评分并列展示差异，便于复核。
- 只有"已确认"的评分才会进入报告统计。

### 5.9 报告与轨迹

汇总所有已确认评分：累计加权得分率、最近一次得分率、最近 30 次评分轨迹、模块得分分析、错因分布。数据不足时显示空态提示，不会用假数据填充。

### 5.10 IRT 专项训练（进阶）

这是一个自适应训练系统，需要你先做少量配置：

1. 在"训练会话 → IRT 专项训练"中建立**知识节点**（如"复数""解析几何"）和**前置依赖**（如"复数是复变函数的前置"）；
2. 为题目设置 IRT 三参数（难度、区分度、猜测度）并映射到知识节点；
3. 完成并确认若干次评分后，系统会估计你在各节点的能力值，并按"上游补弱 → 当前层巩固 → 高难迁移"三种策略推荐题目。

> 能力估计只使用你确认过的评分，样本不足时会明确提示"不应视为个人能力结论"，而不是编造一个精确数值。

### 5.11 备份与恢复

点击顶栏 **本地备份**：

- **导出**：生成一个 `.myeuclid-backup.zip`，包含数据库、全部原始文件和逐文件校验清单（manifest）。建议定期备份到外置硬盘或网盘。
- **恢复**：先"选择备份包并预检"（校验完整性，展示资料/答卷/附件数量，不会立即写入），确认后才会覆盖当前数据。覆盖前软件会自动把现有数据留一份恢复点（存放在数据目录的 `recovery/` 下），误操作可手动找回。

## 6. 隐私清单

- 软件没有账号系统、没有遥测、没有服务器，所有数据在本地。
- AI 请求只会发往**你自己填写**的服务地址；未配置 AI 时，软件不会发出任何网络请求（除界面字体加载，见 §9）。
- 每次真实判卷/讲解前，界面都会注明发送范围；判卷还要求逐次确认。
- `ai-review.log` 只记录运行事件（哪个文件、成功/失败、警告），不含题目内容。

## 7. 常见问题（FAQ）

**Q：导入后没有任何题目出现？**
没有配置 AI 服务时不会自动切分。请到"审核工作台"手工新增题目并发布，或先配置 AI 服务再点"立即 AI 审核补漏"。

**Q：导入后弹出了"请先在 AI 服务中选择一个已启用的默认提供商"的错误提示？**
说明自动审核开关是开着的，但你还没配置 AI。可以去配置，或在"审核工作台"右上角把"导入后自动审核"关掉。

**Q：OCR 识别效果差？**
三个办法：① 用"局部框选识别"对重点区域单独识别，通常更准；② 直接手动修订文本；③ 确认配置了 AI，让自动审核帮你校对错字。另外注意：内置 OCR 目前只支持**英文**（Euclid 竞赛为英文试卷，这正够用），对中文扫描件基本无效。

**Q：AI 自动审核把题目切错了？**
到审核工作台修订草案，或直接在题库中编辑；再次运行自动审核只处理还没有发布过题目的资料，不会重复覆盖你已修订的题。

**Q：AI 判卷的分数可以直接用吗？**
它是"预估草案"，必须经你核对确认后才计入报告。建议把 AI 分数当复核参考，尤其要逐条检查"评分依据"是否与你的作答对应。

**Q：模考中途关掉软件，计时会停吗？**
不会。计时按开始时刻的真实时间计算，重新打开会显示真实的剩余时间。

**Q：换电脑怎么迁移？**
旧电脑导出备份包 → 新电脑安装软件 → 本地备份 → 选择备份包并预检 → 确认恢复。

**Q：手写内容可以导出吗？**
笔迹与作答保存在数据库和备份包中；当前版本没有单独的图片/CSV 导出功能（见 §9）。

## 8. 术语小词典

| 术语 | 意思 |
| --- | --- |
| OCR | 光学字符识别，把图片里的文字变成可编辑文本 |
| 草案 / 确认 | AI 或你产生的评分先以"草案"存在，确认后才进入正式报告与统计 |
| IRT | 项目反应理论，一种用答题记录估计能力和题目难度的教育测量模型 |
| reference key | 每次作答在数据库里的归属编号，用于把作答、评分、报告串起来 |

## 9. 已知限制（使用前必读）

为了不误导你，以下是当前版本**尚未做到**的事情：

1. **单题训练页仍显示示例题面**：从题库点"训练"进入的单题作答页，题面来自软件内置的演示题，不是你选中的那道真实题目。真实题目的完整作答-评分闭环目前请走**全真模考**。
2. **没有公式排版**：输入的 LaTeX 公式（如 `\frac{a}{b}`）会以原文显示，不会被渲染成数学符号。
3. **纸质答案不会被 AI 自动识别**：上传的照片/扫描件只作附件保存；AI 判卷时需要你把作答内容以文字形式粘贴或录入。
4. **内置 OCR 仅支持英文**。
5. **不支持文件夹批量导入、链接（URL）导入**：README 中提到的这些能力尚未实现，请用系统文件选择器多选文件。
6. **没有摄像头拍摄功能**：纸质答案请先拍照再用"上传纸质答案"导入。
7. **IRT 参数需手工录入**：知识节点、依赖关系和题目参数都要手动建立，AI 尚不能自动建议；没有数据前专项训练页是空的。
8. **仅支持 macOS（Apple Silicon）**，界面按桌面尺寸设计。
9. **未通过 Apple 公证**：首次打开需按 §2.1 的方法放行。
10. **浏览器预览模式**（开发者用 `pnpm dev` 启动的网页版）只是界面演示，不读写任何本地数据；请务必使用桌面版完成真实训练。
